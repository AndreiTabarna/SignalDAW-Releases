Version 0.1.13 is available now for both Mac architectures, restoring asynchronous plug-in discovery and repairing incomplete inventories and progress persistence. Windows remains on 0.1.12 while its 0.1.13 installed-upgrade check finishes. Both Mac installers are Developer ID signed, Apple-notarized and stapled. Windows Setup downloads verified payload files automatically and is not Authenticode-signed. For offline Windows installation, place all four payload ZIPs from the Windows 0.1.12 release beside Setup.exe.

The latest release includes production-signed update feeds and [SHA256 checksums](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/download/v0.1.13/SHA256SUMS). Version 0.1.11 remains available for recovery.

Earlier noncommercial/God mode app downloads have been retired. Required model files remain under [v0.1.10](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/tag/v0.1.10) at their original URLs. See the current release notes for system requirements and measured test scope.

Application source code is maintained privately.
