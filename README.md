[Download the commercial 0.1.11 RCs](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/tag/v0.1.11).

| Platform | Download |
| --- | --- |
| Apple silicon Mac | [Notarized DMG](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/download/v0.1.11/SignalDAW-0.1.11-macOS-arm64.dmg) |
| Intel Mac | [Notarized DMG](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/download/v0.1.11/SignalDAW-0.1.11-macOS-x86_64.dmg) |

Both Mac installers are Developer ID signed, Apple-notarized and stapled. Windows Setup downloads its verified payload files automatically; the Windows executable is not Authenticode-signed. For offline Windows installation, place all four payload ZIPs from the release beside Setup.exe.

The release includes production-signed update feeds and [SHA256 checksums](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/download/v0.1.11/SHA256SUMS). Existing Intel testers already on build 0.1.1101 need to install this commercial DMG once; later higher-version releases use the updater.

Earlier noncommercial/God mode app downloads have been retired. Required model files remain under [v0.1.10](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/tag/v0.1.10) at their original URLs. See the current release notes for system requirements and measured test scope.

Application source code is maintained privately.
