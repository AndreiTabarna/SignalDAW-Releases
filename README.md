Version 0.1.13 restores asynchronous plug-in discovery and repairs incomplete/older plug-in inventories, progress persistence and Audio Unit registration detection. Both Mac installers are Developer ID signed, Apple-notarized and stapled. Windows Setup downloads verified payload files automatically and is not Authenticode-signed. For offline Windows installation, place all four payload ZIPs from its release beside Setup.exe.

The latest release includes production-signed update feeds and [SHA256 checksums](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/download/v0.1.13/SHA256SUMS). Versions 0.1.12 and 0.1.11 remain available for recovery.

Earlier noncommercial/God mode app downloads have been retired. Required model files remain under [v0.1.10](https://github.com/AndreiTabarna/SignalDAW-Releases/releases/tag/v0.1.10) at their original URLs. See the current release notes for system requirements and measured test scope.

Application source code is maintained privately.
